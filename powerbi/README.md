# Power BI Analytics Integration

This folder contains the Power BI dashboard used as the business-intelligence layer of the Django sales forecasting system.

## Current setup

- Power BI report: `Sales_Forecasting_PowerBI_Dashboard.pbix`
- Dashboard page in Django: `/powerbi/dashboard/`
- The report is **not published online** in the current portfolio setup.
- Dashboard screenshots are shown inside the Django application for recruiter/demo visibility.

## Power BI pages

1. Sales Overview
2. ML Forecast & Model Performance
3. Future Forecast
4. Combined Forecast

## Live embedding later

If the report is published to Power BI Service in the future, the Django page can be changed from screenshot mode to a secure/public Power BI embed according to the chosen Power BI licensing and sharing method.
